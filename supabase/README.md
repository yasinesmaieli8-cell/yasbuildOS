# زیرساخت پیشنهادی فاز ۳

فایل `001_phase3.sql` در ۱۵ آبان ۱۴۰۵ روی پروژه Supabase اجرا شد. وجود هر دو جدول و فعال بودن امنیت ردیفی و چهار سیاست برای هر جدول با پرس‌وجوی پایگاه داده بررسی شد؛ دسترسی با حساب‌های واقعی هنوز آزموده نشده است. اسکریپت یک بار اجرا می‌شود و در صورت وجود جدول همنام خطا می‌دهد؛ جایگزینی داده‌های موجود را انجام نمی‌دهد. ایجاد جدول‌ها مجوز دسترسی برای نقش `authenticated` و خط‌مشی امنیت ردیفی ایجاد می‌کند؛ نقش ناشناس مجوز جدول ندارد. وابستگی محاسبه به شناسه پروژه و مالک به صورت هم‌زمان کنترل می‌شود. حذف پروژه، محاسبات متعلق به آن را نیز حذف می‌کند.

پیش از کاربرد واقعی، اجرای تراکنش و چهار عمل خواندن، درج، ویرایش و حذف با دو حساب مجزا و کاربر ناشناس باید روی سرویس آزموده شود. مجوز دسترسی مستقیم توسط شناسه متعلق به کاربر دیگر، جعل مالک و اتصال محاسبه به پروژه کاربر دیگر باید رد شود. ورود و بازیابی ایمیلی، سیاست بازیابی داده و پشتیبان، مهاجرت اختیاری پروژه محلی و اتصال رابط کاربری هنوز پیاده‌سازی یا آزموده نشده‌اند. نقش‌های گروهی و مدیر در این طرح وجود ندارند. کلید محرمانه یا service-role نباید در وب‌سایت قرار گیرد.
